# 06 · Checklist de qualidade

## Estrutura e copy
- [ ] "Você" + `[CIDADE]` nos primeiros 2s
- [ ] 3 fotos reais do problema, gravidade crescente, contador 1/3–3/3
- [ ] Profissional apontando para a foto no split
- [ ] Hook termina em pergunta
- [ ] "Fica nesse vídeo…" antes de 8s, com foto DEPOIS no topo
- [ ] Nome + profissão + cidade + bairro + lower-third
- [ ] Inimigo com frequência numérica ("refém de ___ a cada ___")
- [ ] Objeção "já tentei" antes da diferenciação
- [ ] Regra de três "pra cada tipo de ___"
- [ ] 2–3 técnicas com nome técnico + B-roll real
- [ ] Avaliação explicada com 2–4 perguntas concretas
- [ ] Frase "causa real" → antes/depois ×2
- [ ] CTA condicional + botão verde + seta ▼ + canal
- [ ] 200–230 palavras, 55–70s

## Visual
- [ ] Logo/nome visível em todos os talking heads
- [ ] Legendas 1–3 palavras, caixa alta, branco com contorno
- [ ] Jump cuts 2–4s com punch-in, zero respirações

## Anticontaminação (obrigatório: o template não pode vazar a referência)
- [ ] Nenhum `[PLACEHOLDER]` sobrando no roteiro
- [ ] Nenhum destes termos aparece, exceto se fizerem parte do briefing NOVO:
      `Thainá`, `Rodrigues`, `São Carlos`, `Santa Felícia`, `podóloga`, `podologia`, `unha`, `manicure`, `15 dias`, `fotopolimerizável`, `fio de aço`, `curvatura`
- [ ] Arquivos salvos em `<projeto>/roteiro/`, nada escrito dentro da pasta da skill

Comando de checagem (com o caminho completo da skill):
```bash
bash <skill>/roteiro/scripts/checar-contaminacao.sh <projeto>/roteiro
```
Se houver ocorrência legítima (o novo cliente é do mesmo nicho/cidade), justifique no `checklist.md`.

## Compliance
- [ ] Fotos reais, do próprio profissional, com autorização
- [ ] Sem promessa de cura/prazo; regras do conselho do nicho verificadas
- [ ] Urgência/escassez e números de prova social só se forem verdadeiros
